Part 2Key relations and common mistakes

Key relations

  • \(T_t/T = 1 + \frac{\gamma-1}{2}M^2\), \(p_t/p = (T_t/T)^{\gamma/(\gamma-1)}\); \(T_t\) constant if adiabatic, \(p_t\) constant only if also reversible.
  • \(dA/A = (M^2 - 1)\,dV/V\); \(M = 1\) only at a throat; \(A/A^*\) has a subsonic and a supersonic root.
  • Choked: \(\dot m = 0.6847\,p_tA^*/\sqrt{RT_t}\) (γ = 1.4); converging nozzle chokes for \(p_b \le 0.5283p_t\).
  • Shock: \(T_t\) constant, \(p_t\) falls, \(A^*_2 = A^*_1\,p_{t1}/p_{t2}\); the flow behind is subsonic.
  • Fanno: \(\bar fL/D = (\bar f\ell^*/D)_1 - (\bar f\ell^*/D)_2\), friction drives M → 1. Rayleigh: \(q = c_p\Delta T_t\), heating drives M → 1, \(q_{max} = c_p(T_t^* - T_{t1})\).

Common mistakes

  • Using the back pressure as the exit pressure of a choked or supersonic exit. Only a subsonic exit matches \(p_b\).
  • Picking the wrong branch of \(A/A^*\), or forgetting that \(A^*\) changes after a shock.
  • Mixing isentropic * values with Fanno or Rayleigh * values: they are different states.
  • Using Fanning instead of Darcy \(f\) (factor of 4), or °F instead of °R.
  • Forgetting that heating also changes \(T_t\), so the Rayleigh * state is found from the inlet, not assumed.
