Part 2Key relations and common mistakes

Key relations

  • \(a_{st} = x + y/4\) for \(\mathrm{C_xH_y}\) with \(\mathrm{O_2 + 3.76N_2}\) (137.3 kg per kmol O₂); \(\phi = FA/FA_{st} = AF_{st}/AF\).
  • \(\sum_R n\bar h = \sum_P n\bar h + Q_{out}\) with \(\bar h = \bar h_f^\circ + \Delta\bar h\); LHV \(= -\Delta H_{rxn}^\circ/M_{fuel}\) with gaseous water.
  • Burner: \(f = c_p(T_{t4} - T_{t3})/(\eta_bQ_R - c_pT_{t4})\).
  • \(K_p = \frac{\prod n_P^\nu}{\prod n_R^\nu}\left(\frac{p/p_0}{n_{tot}}\right)^{\Delta n}\), a function of T only; reverse → 1/K, scale by n → Kⁿ.
  • Turbine balance \((1+f)(T_{t4} - T_{t5}) = (T_{t3} - T_{t2}) + \alpha(T_{t13} - T_{t2})\); \(F/\dot m_0 = (1+f)u_9 - u_0 + \alpha(u_{19} - u_0)\); \(TSFC = \dot m_f/F\).
  • \(\eta_{th} = \Delta\dot{KE}/(\dot m_fQ_R)\), \(\eta_p = Fu_0/\Delta\dot{KE}\), \(\eta_0 = \eta_{th}\eta_p\). Ideal ramjet: \(M_9 = M_0\).

Common mistakes

  • Forgetting the N₂ mass in AF, or writing excess O₂ for a rich mixture.
  • Using HHV where the problem wants LHV, or forgetting the fuel's own \(\bar h_f^\circ\).
  • Writing \(K_p\) with mole fractions but forgetting the \((p/n)^{\Delta n}\) factor, or using the table value for the reverse reaction.
  • Dropping the \((1 + f)\) in the turbine balance or thrust; using \(T_9\) where \(T_{t9}\) belongs.
  • Specific thrust per core air versus per total air for a turbofan: read which one is asked.
  • US units: forgetting \(g_c\) when converting \(\dot m\,u\) to lbf.
